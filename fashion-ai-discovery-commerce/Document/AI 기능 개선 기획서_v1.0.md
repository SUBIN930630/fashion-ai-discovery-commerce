## 1. 기획 배경

### 1.1 현재 상황

현재 대부분의 패션 커머스 플랫폼은 협업 필터링 기반의 추천 시스템을 운영하고 있습니다. 이는 사용자의 과거 행동 데이터를 기반으로 유사한 상품을 추천하는 방식입니다.

**주요 문제점:**

- 사용자가 한 번 클릭한 스타일/브랜드 위주로만 반복 추천
- 새로운 카테고리나 스타일 발견 기회 부족
- 추천 결과의 다양성 부족으로 인한 탐색 피로도 증가

### 1.2 사용자 불만 사례

29CM와 무신사 사용자들의 실제 VOC(Voice of Customer):

|플랫폼|사용자 의견|
|---|---|
|**29CM**|"파사드패턴 한 번 봤더니 계속 비슷한 브랜드만 나와요"|
|**29CM**|"취향이 바뀌었는데 추천은 그대로예요"|
|**무신사**|"로맨틱, 걸리시 스타일은 추천 안 해줘요"|
|**무신사**|"맨날 같은 옷만 랭킹에 있어요"|

### 1.3 비즈니스 영향

필터버블 현상이 비즈니스에 미치는 부정적 영향:

1. **탐색 피로도 증가** → 앱 이탈률 상승
2. **신규 브랜드 노출 감소** → 판매자 불만 및 입점 이탈
3. **구매 다양성 감소** → 객단가 정체
4. **장기 고객 이탈** → 경쟁 플랫폼으로 이동

무신사 자체 조사 결과(2024.08), 랭킹에 대한 부정/중립 반응이 18%에 달하며, 이 중 12.4%가 "계속 보는 것만 보는 느낌"이라는 부정적 피드백을 남겼습니다.

## 2. 개선 목표

### 2.1 핵심 목표

**대화 맥락을 이해하고, 사용자의 탐색 의도에 맞춰 다양한 상품을 추천하는 AI 챗봇 시스템 구축**

### 2.2 세부 목표

|목표|현재|목표치|측정 방법|
|---|---|---|---|
|**추천 다양성**|0.2~0.3|0.5 이상|추천 결과 내 스타일 분산도|
|**탐색적 추천 CTR**|측정 불가|5% 이상|새로운 카테고리 상품 클릭률|
|**체류 시간**|기준치|+15%|평균 세션 시간|
|**객단가**|기준치|+10%|크로스셀링 증가|
|**부정 피드백**|18%|10% 이하|"비슷한 상품만 나옴" 피드백 비율|

### 2.3 성공 지표 (KPI)

**정량 지표:**

- 대화형 추천 사용률: 전체 사용자의 30% 이상
- 대화 완료율: 시작 대비 70% 이상
- 추천 상품 구매 전환율: 8% 이상

**정성 지표:**

- 사용자 만족도(CSAT): 4.2점 이상 (5점 만점)
- 추천 신뢰도: "도움이 되었다" 80% 이상

## 3. 솔루션 개요

### 3.1 핵심 아이디어

**RAG(Retrieval-Augmented Generation) 기반 탐색적 추천 시스템**

기존 협업 필터링의 "유사도 기반 추천"에 "다양성 보장 메커니즘"을 결합하여, 사용자와의 대화 맥락을 분석해 동적으로 추천 비율을 조정합니다.

### 3.2 작동 원리

```
사용자 대화 입력
    ↓
의도 분석 (탐색 vs 활용)
    ↓
벡터DB 검색 (유사도 + 다양성)
    ↓
MMR 알고리즘으로 결과 통합
    ↓
LLM이 추천 이유 생성
    ↓
대화형 추천 결과 제시

```

### 3.3 차별화 포인트

|기존 시스템|개선 시스템|
|---|---|
|유사도 점수만 최적화|유사도 + 다양성 점수 균형|
|정적 추천 (항상 같은 비율)|동적 추천 (대화 맥락에 따라 비율 조정)|
|추천 이유 없음|AI가 추천 이유를 자연어로 설명|
|단방향 추천|양방향 대화로 취향 탐색|

### 4.2 핵심 컴포넌트

### 4.2.1 Chat Interface Layer

**역할:** 사용자와의 대화 인터페이스 제공

**기능:**

- 텍스트 기반 대화 입력/출력
- 대화 히스토리 관리
- 세션 상태 유지

**기술 스택:**

- Frontend: React.js + WebSocket
- Backend: FastAPI + Redis (세션 관리)

### 4.2.2 Intent Analysis Module

**역할:** 사용자의 대화 의도 분석

**기능:**

- 탐색 의도 감지 ("새로운 스타일 보여줘", "다른 거 없어?")
- 카테고리 전환 감지 (평소 후드티 → 재킷 요청)
- 탐색/활용 비율 동적 결정

**예시:**

|사용자 입력|감지된 의도|추천 비율|
|---|---|---|
|"새로운 스타일 보여줘"|탐색 모드|탐색 70% / 활용 30%|
|"후드티 추천해줘"|활용 모드|활용 70% / 탐색 30%|
|"재킷 있어?" (평소 후드티)|카테고리 전환|브릿지 50% / 활용 30% / 탐색 20%|

**기술 스택:**

- LLM: GPT-4 또는 Claude
- Prompt Engineering: Few-shot learning

### 4.2.3 Vector DB Search

**역할:** 상품 임베딩 기반 유사도 검색

**구조:**

```
사용자 취향 벡터: [0.12, 0.45, 0.78, ...]
                    ↓
        ┌───────────┴───────────┐
        │                       │
        ▼                       ▼
  유사도 높은 검색        유사도 낮은 검색
  (similarity > 0.8)     (similarity < 0.5)
        │                       │
        └───────────┬───────────┘
                    │
                    ▼
              [검색 결과 통합]

```

**검색 파라미터:**

|검색 유형|유사도 범위|용도|비중|
|---|---|---|---|
|**High Similarity**|> 0.8|기존 취향|30%|
|**Mid Similarity**|0.5~0.8|브릿지 스타일|30%|
|**Low Similarity**|0.3~0.5|새로운 발견|40%|

**기술 스택:**

- Vector DB: Pinecone 또는 Weaviate
- Embedding Model: text-embedding-3-large (OpenAI)

### 4.2.4 MMR Algorithm

**역할:** 유사도와 다양성의 균형 보장

**수식:**

```
MMR = λ × Similarity(q, d) - (1-λ) × max Similarity(d, d')
                                        d'∈R

q: 쿼리 (사용자 취향)
d: 후보 상품
R: 이미 선택된 추천 결과
λ: 유사도/다양성 가중치 (기본 0.7)

```

**작동 방식:**

1. 첫 번째 상품: 유사도 점수가 가장 높은 상품 선택
2. 두 번째 이후: 유사도는 높지만, 이미 선택된 상품과는 다른 상품 선택
3. 10개 선택 완료까지 반복

**예시:**

```
[선택 과정]
1번: 검정 후드티 (유사도 0.95)
2번: 네이비 후드티 (유사도 0.93) ✗ → 너무 비슷
     → 카키 워크 재킷 (유사도 0.78) ✓ → 선택
3번: 미니멀 맨투맨 (유사도 0.82, 다양성 확보) ✓

```

**기술 스택:**

- Python: NumPy, SciPy
- 커스텀 MMR 구현

### 4.2.5 LLM Response Generator

**역할:** 추천 이유를 자연어로 생성

**프롬프트 구조:**

```
시스템 프롬프트:
당신은 패션 전문 쇼핑 어시스턴트입니다.
추천 상품에 대해 다음 정보를 활용해 설명해주세요:

- 사용자의 기존 취향: {user_style_profile}
- 상품의 스타일: {product_style}
- 유사도 점수: {similarity_score}
- 추천 유형: {recommendation_type}

규칙:
1. 탐색적 추천은 "새로운 발견"으로 프레이밍
2. 왜 이 상품이 사용자에게 어울리는지 구체적으로 설명
3. 다른 고객의 구매 패턴을 활용해 신뢰감 형성
4. 친근하고 대화체로 작성 (이모지 적절히 사용)

```

**생성 예시:**

|추천 유형|생성된 설명|
|---|---|
|**기존 취향**|"평소 좋아하시는 스트릿 스타일이에요. 12,500명이 구매했고, '핏이 예뻐요'라는 후기가 많아요."|
|**브릿지 스타일**|"스트릿 감성은 유지하면서 아메카지 무드를 살짝 더했어요. 32%의 비슷한 취향 고객분들이 새롭게 시도하신 스타일이에요."|
|**탐색적 추천**|"평소 스타일과는 다르지만, 요즘 MZ 사이에서 핫한 워크웨어 스타일이에요! 스트릿 아이템과 믹스매치하면 새로운 무드를 연출할 수 있어요. 한번 도전해보세요! 🔥"|

**기술 스택:**

- LLM: GPT-4 Turbo
- 템플릿 관리: Jinja2

**대화 흐름:**

```

🤖 AI: 민수님, 안녕하세요! 새로운 스타일을 찾고 계시군요! 👀
      민수님의 스트릿 감성을 살리면서 요즘 뜨는 스타일 보여드릴게요.

      💡 [새로운 발견]

      1️⃣ 아메카지 워크 재킷 - 89,000원

         민수님처럼 스트릿 좋아하시는 분들이 최근 많이 시도하는 스타일이에요!
         ⭐ 비슷한 취향 고객 32%가 새로 구매

         검정 바지만 입으셨다면, 카키 컬러 도전!
         스트릿 상의와 의외로 잘 어울려요

      🏠 [기존 취향]

      물론 평소 스타일도 준비했어요 😊
      4️⃣ 스트릿 후드티 - 65,000원
```
