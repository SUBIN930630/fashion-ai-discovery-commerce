# 챗봇 대화 히스토리 내보내기 가이드

## 🎯 목적
AWS에 배포된 실제 운영 중인 챗봇에서 사용자들이 주고받은 대화 내용을 JSON 형식으로 정리하여 내보내기

## 📋 사용 방법

### 1단계: AWS 서버 접속
```bash
ssh -i your-key.pem ubuntu@your-aws-server-ip
```

### 2단계: 프로젝트 디렉토리로 이동
```bash
cd /path/to/fashion-ai-discovery-commerce
# 또는 Docker를 사용하는 경우
cd ~/fashion-ai-discovery-commerce
```

### 3단계: 스크립트 실행

#### 방법 1: Docker 컨테이너 내부에서 실행
```bash
# 백엔드 컨테이너 접속
docker exec -it fashion-ai-backend bash

# 스크립트 실행
cd /app
python scripts/export_chat_history.py
```

#### 방법 2: 로컬에서 실행 (데이터베이스 연결 필요)
```bash
cd backend
python scripts/export_chat_history.py
```

### 4단계: 옵션 사용 예시

#### 최근 100개 대화만 내보내기
```bash
python scripts/export_chat_history.py --limit 100
```

#### 특정 기간 데이터만 내보내기
```bash
# 2025년 1월 데이터만
python scripts/export_chat_history.py --start-date 2025-01-01 --end-date 2025-01-31
```

#### 출력 파일명 지정
```bash
python scripts/export_chat_history.py --output chat_data_2025_01.json
```

## 📁 출력 파일 위치
스크립트를 실행하면 프로젝트 루트 디렉토리에 `chat_history_export.json` 파일이 생성됩니다.

## 📊 출력 JSON 구조

```json
{
  "export_info": {
    "export_date": "2025-01-02T12:00:00",
    "total_sessions": 50,
    "total_conversations": 150,
    "total_messages": 300
  },
  "statistics": {
    "total_sessions": 50,
    "total_conversations": 150,
    "total_messages": 300,
    "user_messages": 150,
    "assistant_messages": 150
  },
  "conversations": [
    {
      "session_id": "session_123",
      "user_id": "user_456",
      "timestamp": "2025-01-02T10:30:00",
      "user_message": "미니멀 셔츠 추천해줘",
      "assistant_message": "미니멀 스타일의 셔츠를 추천해드릴게요! ...",
      "intent": "감성·스타일",
      "confidence": 0.95,
      "exploration_intent": false,
      "recommendations": [
        {
          "id": "prod001",
          "name": "미니멀 코튼 셔츠",
          "brand": "브랜드A",
          "price": 59000
        }
      ],
      "recommendations_count": 1
    }
  ]
}
```

## 🔍 주요 필드 설명

- **user_message**: 사용자가 입력한 질문
- **assistant_message**: 챗봇이 응답한 내용
- **intent**: 분석된 의도 (가격·가성비, 감성·스타일, 시즌·날씨, 체형·핏, 코디·상황)
- **confidence**: 의도 분석 신뢰도 (0.0 ~ 1.0)
- **exploration_intent**: 탐색 의도 여부 (true/false)
- **recommendations**: 추천된 상품 리스트
- **recommendations_count**: 추천된 상품 개수

## 💡 활용 예시

### Python으로 데이터 분석
```python
import json
from collections import Counter

# JSON 파일 읽기
with open('chat_history_export.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 가장 많이 나온 질문 유형
intents = [c['intent'] for c in data['conversations'] if c['intent']]
intent_counts = Counter(intents)
print("의도별 질문 분포:")
for intent, count in intent_counts.most_common():
    print(f"  {intent}: {count}회")

# 평균 추천 개수
avg_recommendations = sum(
    c['recommendations_count'] 
    for c in data['conversations']
) / len(data['conversations'])
print(f"\n평균 추천 개수: {avg_recommendations:.2f}개")

# 탐색 의도 비율
exploration_count = sum(
    1 for c in data['conversations'] 
    if c.get('exploration_intent')
)
exploration_ratio = exploration_count / len(data['conversations']) * 100
print(f"탐색 의도 비율: {exploration_ratio:.1f}%")
```

## ⚠️ 주의사항

1. **데이터베이스 연결**: 스크립트 실행 전에 데이터베이스 연결이 정상인지 확인하세요.

2. **대용량 데이터**: 전체 데이터를 내보낼 경우 시간이 오래 걸릴 수 있습니다. 필요시 `--limit` 옵션을 사용하세요.

3. **파일 크기**: 대화가 많을 경우 JSON 파일이 매우 커질 수 있습니다 (수백 MB 이상).

4. **권한**: 데이터베이스 읽기 권한이 필요합니다.

5. **보안**: 내보낸 JSON 파일에는 사용자 대화 내용이 포함되므로 보안에 주의하세요.
