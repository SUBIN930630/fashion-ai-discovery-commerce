- `프롬프트 규칙 및 답변 작성 가이드_v1.0.md`

## 1. Intent 분류 검증

**목적**: 사용자 질문을 5가지 Intent로 정확히 분류하는지 확인

### 1.1 가격·가성비 기반 Intent

**테스트 질문**: "10만 원대 자켓 추천해줘"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| Intent 정확도 | "가격·가성비" Intent로 분류됨 | ☐ |
| 가격대 언급 | 답변에 가격대(10만 원대) 언급됨 | ☐ |
| 가성비 강조 | "가성비", "활용도", "부담 없는" 등 키워드 포함 | ☐ |
| 추천 상품 가격 | 추천 상품이 10만 원대 근처임 (8만~12만 원) | ☐ |

**예상 답변 구조**:
```
가성비 좋은 자켓을 찾고 계시는군요! 👔

💡 새로운 발견
1. [상품명] - [가격]원
   - 가성비 좋은 설명

🏠 내 취향
2. [상품명] - [가격]원
   - 기존 취향 기반 설명
```

---

### 1.2 감성·스타일 기반 Intent

**테스트 질문**: "29CM 감성의 미니멀 셔츠 추천해줘"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| Intent 정확도 | "감성·스타일" Intent로 분류됨 | ☐ |
| 스타일 키워드 인식 | "29CM", "미니멀" 키워드가 답변에 반영됨 | ☐ |
| 스타일 설명 | 답변에 "차분한 컬러", "여유 있는 핏" 등 스타일 설명 포함 | ☐ |
| 브랜드 다양성 | 다양한 브랜드 추천 (같은 브랜드 최대 2개) | ☐ |

**예상 답변 구조**:
```
29CM 감성의 미니멀 셔츠를 찾으시는군요! ✨

💡 새로운 발견
1. [상품명] (새로운 브랜드)
   - 미니멀 스타일 설명

🏠 내 취향
2. [상품명]
   - 기존 취향 기반 설명
```

---

### 1.3 시즌·날씨 기반 Intent

**테스트 질문**: "봄에 입기 좋은 자켓 뭐야?"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| Intent 정확도 | "시즌·날씨" Intent로 분류됨 | ☐ |
| 시즌 인식 | "봄" 시즌이 답변에 반영됨 | ☐ |
| 날씨 고려 | "가볍게", "통기성", "일교차" 등 날씨 관련 설명 포함 | ☐ |
| 계절 적합성 | 추천 상품이 봄에 적합한 소재/디자인임 | ☐ |

---

### 1.4 체형·핏 기반 Intent

**테스트 질문**: "키 175cm인데 오버핏으로 입기 좋은 봄 자켓 추천해줘"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| Intent 정확도 | "체형·핏" Intent로 분류됨 | ☐ |
| 체형 정보 활용 | 키(175cm) 정보가 답변에 반영됨 | ☐ |
| 핏 정보 활용 | "오버핏" 요구사항이 답변에 반영됨 | ☐ |
| 기장/핏 설명 | "기장", "비율", "핏" 등 구체적 설명 포함 | ☐ |

---

### 1.5 코디·상황 기반 Intent

**테스트 질문**: "출근할 때 입기 좋은 코디"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| Intent 정확도 | "코디·상황" Intent로 분류됨 | ☐ |
| 상황 인식 | "출근" 상황이 답변에 반영됨 | ☐ |
| TPO 적합성 | 출근룩에 적합한 상품 추천 (단정한 스타일) | ☐ |
| 코디 제안 | 단일 아이템이 아닌 코디 조합 제안 | ☐ |

## 2. 필터버블 해소 검증

**목적**: "매번 비슷한 상품만 보여요" 문제를 해결하는지 확인

### 2.1 70/30 비율 준수

**테스트 방법**: 
1. 첫 질문: "자켓 추천해줘"
2. 답변에서 "💡 새로운 발견"과 "🏠 내 취향" 섹션의 상품 개수 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 새로운 발견 비율 | 전체 추천 중 70%가 "💡 새로운 발견" 섹션에 있음 | ☐ |
| 기존 취향 비율 | 전체 추천 중 30%가 "🏠 내 취향" 섹션에 있음 | ☐ |
| 섹션 표시 | "💡 새로운 발견"과 "🏠 내 취향" 섹션이 명확히 구분됨 | ☐ |
| 최소 개수 | 각 섹션에 최소 1개 이상의 상품이 포함됨 | ☐ |

**계산 예시**:
- 전체 추천 5개 → 새로운 발견 3~4개 (70%), 기존 취향 1~2개 (30%)
- 전체 추천 10개 → 새로운 발견 7개 (70%), 기존 취향 3개 (30%)

---

### 2.2 스타일 다양성

**테스트 방법**: 
1. 질문: "자켓 추천해줘"
2. 추천된 상품의 스타일 태그 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 스타일 개수 | 최소 3개 이상의 서로 다른 스타일 태그 포함 | ☐ |
| 스타일 분산 | 한 스타일에 편중되지 않음 (예: 미니멀만 3개 X) | ☐ |
| 브랜드 다양성 | 같은 브랜드가 3개 이상 아님 (최대 2개) | ☐ |

---

### 2.3 새로운 발견 프레이밍

**테스트 방법**: 답변에서 "💡 새로운 발견" 섹션 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 섹션 표시 | "💡 새로운 발견" 또는 "새로운 발견" 문구 포함 | ☐ |
| 설명 멘트 | "평소와 다른 스타일", "새로운 브랜드" 등 설명 포함 | ☐ |
| 기존 취향 구분 | "🏠 내 취향" 섹션과 명확히 구분됨 | ☐ |

---

### 2.4 탐색 의도 감지

**테스트 질문**: "다른 거 없어?" 또는 "새로운 스타일 보여줘"

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 탐색 의도 인식 | "exploration_intent: True"로 분류됨 | ☐ |
| 높은 탐색 비율 | 새로운 발견 비율이 70% 이상 (일반적으로 80% 이상) | ☐ |
| 다양한 스타일 | 이전 추천과 완전히 다른 스타일 제시 | ☐ |

---

### 2.5 브랜드 다양성

**테스트 방법**: 
1. 질문: "자켓 추천해줘"
2. 추천된 상품의 브랜드 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 브랜드 제한 | 같은 브랜드가 최대 2개까지만 추천됨 | ☐ |
| 브랜드 분산 | 최소 2개 이상의 서로 다른 브랜드 포함 | ☐ |

---

### 2.6 카테고리 다양성

**테스트 방법**: 
1. 질문: "아우터 추천해줘"
2. 추천된 상품의 카테고리 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 카테고리 일치 | 요청한 카테고리(아우터)와 일치하는 상품 추천 | ☐ |
| 하위 카테고리 다양성 | 자켓, 코트, 패딩 등 다양한 하위 카테고리 포함 | ☐ |

## 3. 답변 구조 검증

**목적**: 4단계 답변 구조를 준수하는지 확인

### 3.1 1단계: 공감 + 의도 확인

**테스트 방법**: 모든 답변의 시작 부분 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 공감 표현 | "~을 찾고 계시는군요!", "~하시는군요!" 등 공감 표현 포함 | ☐ |
| 의도 확인 | 사용자 질문의 의도를 간단히 요약 | ☐ |
| 이모지 사용 | 적절한 이모지 1개 사용 (과하지 않게) | ☐ |

**예시**:
- ✅ "가성비 좋은 자켓을 찾고 계시는군요! 👔"
- ✅ "29CM 감성의 미니멀 셔츠를 찾으시는군요! ✨"
- ❌ "자켓 추천드릴게요" (공감 표현 없음)

---

### 3.2 2단계: 새로운 발견 추천 (70%)

**테스트 방법**: 답변의 "💡 새로운 발견" 섹션 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 섹션 표시 | "💡 새로운 발견" 또는 "새로운 발견" 문구 포함 | ☐ |
| 상품 개수 | 전체 추천의 70%에 해당하는 상품 수 | ☐ |
| 상품 정보 | 각 상품에 이름, 가격, 브랜드 포함 | ☐ |
| 추천 이유 | 각 상품에 "왜 추천하는지" 이유 설명 포함 | ☐ |
| 새로운 스타일 표시 | "새로운 스타일", "새로운 브랜드" 등 표시 | ☐ |

---

### 3.3 3단계: 기존 취향 추천 (30%)

**테스트 방법**: 답변의 "🏠 내 취향" 섹션 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 섹션 표시 | "🏠 내 취향" 또는 "내 취향" 문구 포함 | ☐ |
| 상품 개수 | 전체 추천의 30%에 해당하는 상품 수 | ☐ |
| 상품 정보 | 각 상품에 이름, 가격, 브랜드 포함 | ☐ |
| 기존 취향 언급 | "평소 좋아하시는 스타일", "기존 취향" 등 언급 | ☐ |

---

### 3.4 4단계: 꼬리질문 or 대안 제시

**테스트 방법**: 답변의 마지막 부분 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 질문 포함 | 답변 끝에 꼬리질문 1~2개 포함 | ☐ |
| 질문 개수 | 최대 2개 이하 (3개 이상 연속 질문 금지) | ☐ |
| 질문 형식 | 선택지 제시형 또는 단답형 질문 | ☐ |
| 대안 제시 | 질문 대신 대안 제시도 가능 (예: "다른 스타일도 있어요") | ☐ |

**예시**:
- ✅ "혹시 선호하시는 컬러가 있으세요?"
- ✅ "캐주얼 vs 미니멀 중 선호는요?"
- ❌ "사이즈는요? 컬러는요? 예산은요?" (3개 연속 질문)

## 4. 재추천 방지 검증

**목적**: 같은 상품을 반복 추천하지 않는지 확인

### 4.1 최근 5회 대화 제외

**테스트 방법**: 
1. 같은 질문을 5회 연속 질문
2. 각 답변에서 추천된 상품 ID 기록
3. 6번째 질문에서 이전 5회에 추천된 상품이 제외되는지 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 상품 제외 | 최근 5회 대화에서 추천한 상품이 6번째 답변에 포함되지 않음 | ☐ |
| 새로운 상품 | 6번째 답변에 새로운 상품이 포함됨 | ☐ |

---

### 4.2 클릭 안 한 상품 제외

**테스트 방법**: 
1. 질문: "자켓 추천해줘"
2. 추천된 상품 중 하나를 클릭하지 않음
3. 같은 질문 다시 질문
4. 클릭하지 않은 상품이 제외되는지 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 클릭 안 한 상품 제외 | 이전에 추천했으나 클릭하지 않은 상품이 다시 추천되지 않음 | ☐ |
| 클릭한 상품 포함 가능 | 클릭한 상품은 다시 추천될 수 있음 (단, 최근 5회 제외 규칙 적용) | ☐ |

---

### 4.3 같은 브랜드 제한

**테스트 방법**: 
1. 질문: "자켓 추천해줘"
2. 추천된 상품의 브랜드 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 브랜드 제한 | 같은 브랜드가 최대 2개까지만 추천됨 | ☐ |
| 브랜드 다양성 | 최소 2개 이상의 서로 다른 브랜드 포함 | ☐ |

---

### 4.4 스타일 다양성 강제

**테스트 방법**: 
1. 질문: "자켓 추천해줘"
2. 추천된 상품의 스타일 태그 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 스타일 개수 | 최소 3개 이상의 서로 다른 스타일 태그 포함 | ☐ |
| 스타일 분산 | 한 스타일에 편중되지 않음 | ☐ |

## 5. 톤앤매너 검증

**목적**: 친근하고 자연스러운 대화체를 사용하는지 확인

### 5.1 대화체 사용

**테스트 방법**: 모든 답변의 문체 확인

| 검증 항목 | 통과 기준 | 체크 |
|---------|---------|------|
| 존댓말 사용 | 모든 답변이 존댓말로 작성됨 | ☐ |
| 자연스러운 문체 | 딱딱한 문어체가 아닌 자연스러운 구어체 | ☐ |
